# Документация по компонентам Primo RPA

Репозиторий содержит русскоязычные и англоязычные материалы по настройке и использованию компонентов Primo RPA. Документация подготовлена для производителя Primo RPA в рамках коммерческой работы и рассчитана на технических специалистов, которые настраивают интеграции, автоматизацию и связанные корпоративные сервисы.

**Моя роль:** самостоятельное исследование функциональности предоставленного программного продукта, проверка сценариев использования, систематизация информации и подготовка технической документации. Репозиторий не означает участия в разработке платформы, проектировании её архитектуры или реализации описанных API.

> **English summary.** Bilingual technical documentation created for the Primo RPA vendor. The work covered product feature research, information structuring, and preparation of configuration and usage guides. It does not claim authorship of the platform, its architecture, or the documented APIs.
